# AI-Powered Energy Forecasting

This repository contains the development work for the ICT Innovation Project:

**Forecasting Model Development: AI-Powered Energy Prediction**

## Project Objective

The aim of this project is to develop a prototype forecasting system that predicts future electricity load using historical energy data and machine learning / deep learning models.

## Project Tasks

- Data collection and exploration
- Data cleaning and preprocessing
- Feature engineering
- Time-based feature creation
- Lag feature creation
- Baseline model development
- Model comparison and evaluation
- Final reporting and presentation

## Models

The project will compare different forecasting approaches, including:

- Linear Regression
- XGBoost
- LSTM

## Evaluation Metrics

Model performance will be evaluated using:

- MAE – Mean Absolute Error
- RMSE – Root Mean Squared Error
- MAPE – Mean Absolute Percentage Error
